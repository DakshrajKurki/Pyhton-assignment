# 🐍 Python Fundamentals — 11 Exercises

Eleven short programs covering core Python: arithmetic, conditionals, Boolean logic, strings, lists and nested lists. Every line is commented to explain what it does.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Jupyter](https://img.shields.io/badge/Jupyter-F37626?style=flat-square&logo=jupyter&logoColor=white)

## Exercises

| # | Task | Concept |
|---|---|---|
| 1 | Add, subtract, multiply and divide two numbers | Arithmetic operators |
| 2 | Find the larger of two numbers | `if / else` |
| 3 | Combine two Boolean inputs | Boolean logic, string methods |
| 4 | Length of a word | `len()` |
| 5 | Personalised greeting from name and age | Input & formatted output |
| 6 | Search for a word in a sentence | String membership |
| 7 | Collect three numbers into a list | Lists & loops |
| 8 | Store favourite fruits | List building |
| 9 | Read five numbers and summarise them | Loops & aggregation |
| 10 | First and last five elements of a list | Slicing |
| 11 | Student names with marks in three subjects | Nested lists |
